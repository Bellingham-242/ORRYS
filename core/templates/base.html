Installer sur iPhone / iPad

Pour ajouter l'application à votre écran d'accueil :

  1. Appuyez sur le bouton Partager dans Safari.
  2. Faites défiler vers le bas et sélectionnez Sur l'écran d'accueil .
  3. Validez en appuyant sur Ajouter.
Installer ORRYS Numérique

Pour installer l'application sur votre appareil :

  1. Dans la barre d'adresse ou le menu du navigateur : cliquez sur l'icône d'installation ou Ajouter à l'écran d'accueil.
  2. Sur PC, vous pouvez aussi cliquer sur les trois petits points (...) > Applications > Installer ce site.
L'application fonctionne en mode natif et enregistre vos accès rapidement.
